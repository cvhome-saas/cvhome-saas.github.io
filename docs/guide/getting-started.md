# Getting Started with cvhome

Welcome to cvhome! This open-source platform allows you to manage multiple e-commerce stores, either for your own private operations or as a public SaaS offering.

To help you find the information you need quickly, please choose the path that best describes your primary goal:

## 🚀 I want to Deploy & Use cvhome

If your goal is to set up and run your own instance of cvhome:

1.  **Quick Local Demo (Recommended First Step):** To quickly run `cvhome` on your local machine for evaluation using Docker, follow the **Quick Start with Docker Compose** guide. This is the fastest way to see it in action.
2.  **Understand the Basics:** Before a real deployment, it's highly recommended to grasp the **Core Concepts**, especially the **Dual Cluster Architecture** and **Multi-Tenancy Models**.
3.  **Cloud Deployment Options:** Review the **Deployment Overview** to understand the general strategies for cloud deployment.
4.  **Deploy on AWS:** Follow the detailed **AWS ECS Deployment Guide** which utilizes Terraform and GitHub Actions for a production-like setup.
5.  **Configuration:** Learn about essential **Environment Variables** required for configuration.
6.  **Customization:** Explore how to customize the appearance using the **Theming Guide**.

## 🧑‍💻 I want to Understand the Architecture or Contribute

If you're interested in learning how cvhome is built, developing new features, fixing bugs, or contributing back to the project:

1.  **High-Level Picture:** Start with the [**Architecture Overview**](architecture-overview.md) to see the components and technology stack.
2.  **Foundational Ideas:** Ensure you understand the [**Core Concepts**](./core-concepts.md).
3.  **Set Up Locally:** Follow the [**Local Development Setup Guide**](../development/local-setup.md) to get the project running on your machine.
4.  **Contribution Guidelines:** Read the [**Contributing Guide**](../development/contributing.md) for details on code standards, pull requests, and the development workflow.

## 🤔 Just Exploring?

If you're just browsing and want to learn more about what makes cvhome unique:

*   Read the [**Introduction**](./introduction.md) for a summary of the value proposition.
*   Dive into the [**Core Concepts**](./core-concepts.md) to understand the foundational design.
*   Check out the [**Architecture Overview**](architecture-overview.md).
